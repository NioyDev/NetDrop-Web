Documentación de NetDrop

Aprende cómo configurar, ejecutar y extender NetDrop tanto en su edición clásica en Python como en su próxima edición en Rust.

Inicio Rápido

NetDrop está diseñado para funcionar inmediatamente después de descargarse, sin requerir instalaciones de Python o bibliotecas externas en tu sistema.

Ejecución en Windows

  1. Descarga el instalador NetDrop-Setup.exe o el ejecutable portable NetDrop.exe desde la sección de descargas.
  2. Ejecuta el archivo. Si el Firewall de Windows solicita permiso para comunicarse en redes privadas, acepta para permitir la conexión del puerto 5000.
  3. Se abrirá la ventana de escritorio con el código QR. ¡Apunta la cámara de tu móvil para acceder de inmediato!

Ejecución en Linux

# Si descargaste el paquete .deb (Debian, Ubuntu, Mint): sudo dpkg -i netdrop-installer.deb # Si usas la versión comprimida portátil: unzip NetDrop-Linux-x64.zip cd NetDrop-Linux-x64 ./NetDrop

Requisitos de Red

Para que los dispositivos puedan descubrirse y comunicarse:

  • La computadora anfitriona y los dispositivos móviles deben estar conectados a la misma red Wi-Fi o red de área local (LAN).
  • No se requiere conexión a internet hacia el exterior. NetDrop funciona perfectamente en redes aisladas (offline).
  • En redes Wi-Fi de hoteles o universidades con Client Isolation (aislamiento de clientes), los dispositivos pueden tener restringida la visibilidad mutua. En ese caso, puedes activar la zona Wi-Fi portátil (Hotspot) de tu móvil o PC.

Arquitectura de NetDrop Python (v2.1.2)

La versión clásica de NetDrop está construida combinando componentes maduros del ecosistema Python:

Pila Tecnológica Python:
Flask (rutas y API) + Waitress (servidor WSGI multihilo para producción) + Pywebview (interfaz gráfica de escritorio nativa basada en Chromium / Webview2).

Gestión de Memoria y Subida en Chunks

Al transferir archivos grandes (videos 4K, archivos ISO o zips), los navegadores móviles pueden experimentar cierres inesperados por falta de memoria RAM. NetDrop resuelve esto mediante:

  • División en fragmentos de 2 MB: El cliente genera slices del Blob binario en Javascript y los transmite secuencialmente.
  • Directorio temporal: El servidor almacena los fragmentos en temp_chunks/.
  • Movimiento atómico: Al recibir el último chunk, se unen los fragmentos y se trasladan atómicamente a Files/.

Arquitectura de NetDrop Rust (En Desarrollo)

NetDrop-Rust es la evolución del proyecto desarrollada desde cero para alcanzar el máximo rendimiento posible con un consumo ínfimo de memoria:

Pila Tecnológica Rust:
Axum (framework HTTP ergonómico y rápido) + Tokio (motor de runtime asíncrono no bloqueante) + Tower (middlewares y capas de servicio).

En la versión Rust, las transferencias se procesan como flujos directos de bytes (streaming) sin cargar el archivo completo en memoria intermedia, reduciendo el consumo de RAM a menos de 15 MB incluso durante transferencias masivas a velocidad gigabit.

Puertos y Firewall

NetDrop utiliza el puerto estándar 5000. Si tienes un cortafuegos activo en Linux (como UFW) o en Windows, puedes habilitarlo con:

# En Linux con UFW: sudo ufw allow 5000/tcp # En Windows (PowerShell Administrador): New-NetFirewallRule -DisplayName "NetDrop Server" -Direction Inbound -LocalPort 5000 -Protocol TCP -Action Allow

Sistema de Temas en JSON

NetDrop incluye soporte para esquemas de color definidos mediante archivos .json. Puedes crear tu propia paleta copiando la siguiente estructura:

{ "id": "mi-tema-personalizado", "name": "Mi Tema Personal", "bgBase": "#1a1918", "surface": "#262422", "surfaceHover": "#33302c", "text": "#d6d2c9", "textHeading": "#ffffff", "textMuted": "#9c9689", "accent": "#d97706", "accentHover": "#b45309", "accentBg": "rgba(217, 119, 6, 0.15)", "border": "#3a3733", "borderHover": "#4d4944", "danger": "#e11d48", "dangerHover": "#be123c", "dangerBg": "rgba(225, 29, 72, 0.15)" }
